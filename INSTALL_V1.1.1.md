# Ajuste de textos v1.1.1

Este paquete se basa en v1.1 y modifica únicamente `src/App.jsx`:

- Se retira del encabezado «UN GRUPO, MUCHOS REGALOS Y UN GRAN SECRETO».
- Se elimina el eslogan «Tú pon los regalos, nosotros el secreto» y el párrafo introductorio del hero.
- El encabezado mantiene «A mí me tocó... ¡Y no te voy a decir quién!».
- El pie de página muestra solo «¡Y NO TE VOY A DECIR QUIÉN!».

## Despliegue
1. Copiar `src/App.jsx` al repositorio existente (o reemplazar todos los archivos con el paquete, conservando `.git`).
2. Commit y Push en GitHub.
3. Verificar GitHub Actions y recargar la página.

No necesita SQL ni actualizar la Edge Function.
